## 2. 配置、实例与租约

| 所有者 | 关键字段 | 数据来源与读写时点 |
| --- | --- | --- |
| 池组件 Inspector | `GameObject prefab`、`int capacity = 1`、`int prewarmCount = 0` | Prefab 引用必填。`Awake` 要求容量至少 1，预热量在 0 至容量之间，CombatDemo 填 HitSpark、2、1。开场后使用该组配置 |
| 池组件 | `Slot[] slots`、`int assignedCount`、`Stack<int> available` | 初始化分配固定长度数组。assignedCount 从 0 起记录已分配编号的数量，外部销毁或重置失败仍保留这个编号。栈中只存当前可领取的编号，一个编号最多入栈一次 |
| 池组件 | `Transform creationRoot`、`bool accepting`、`bool recycling` | Awake 创建永久失活的临时父节点。两个标志初始为 false，启停组件控制接受请求，批量清场期间临时关闭租用 |
| 单个槽位 | `GameObject Instance`、`IPoolReset[] Resets` | 每次在该编号下创建实体时缓存实例及其根和全部子节点的重置组件，包含失活子节点。淘汰或发现对象丢失后，下次创建时重新取得组件 |
| 单个槽位 | `bool Rented = false`、`ulong Version = 0` | 每次借出先标记占用并递增版本，首次版本为 1。归还先清借出标志，重建实例、重新启用和 RecycleAll 均保留槽位版本序列 |
| 只读 `PoolLease` | `ScenePrefabPool owner`、`int slotIndex`、`ulong version` | 由原池在领取槽位后写入。复制结构体得到同一轮租用的另一份凭据，任一副本成功归还后，所有副本同时失效 |
| 火花组件 | `ParticleSystem particles`、`PoolLease lease` | particles 在 Prefab Inspector 绑定本根节点粒子系统，配置回调通过 `Bind` 传入租约，播放协程捕获值副本，归还时清空粒子与组件持有的租约 |

**有效性**　`lease.IsActive` 为真需要原池仍存在、该槽标记为借出、版本相等且实例仍存在。它在配置回调期间已经为真，此时对象仍失活。默认租约、已归还的副本、旧轮次的回调，以及实例或池已实际销毁的租约都返回 false。查询只读状态，不会创建对象

**父级与姿态**　池先在失活的创建节点下实例化 Prefab，把实例设为失活，再以 `worldPositionStays = false` 挂到池节点下，避免创建和预热触发播放。活动和闲置实例都以池为父节点，配置回调可写世界位置、朝向和本次显示值。归还后恢复根节点的 Prefab 局部位置、旋转和缩放。若组件改过子节点或 UI 的锚点、文字、颜色等内容，由修改这些值的组件实现 `IPoolReset`。临时 UI 可将整个池挂在目标 Canvas 下，由调用方填写 `anchoredPosition`

## 3. 公开接口与执行顺序

### TryRent

`bool ScenePrefabPool.TryRent(Action<GameObject, PoolLease> configure, out PoolLease lease)`

1. 将输出置为默认租约。池未开放、正在清场或容量已满时返回 false，配置回调不会执行
2. 优先从闲置栈取编号，若该实例已被销毁则在原编号下重建。栈空且仍有未分配编号时按需创建。两个来源都用尽时，只在这次请求中查找借出期间已被外部销毁的实例，找到则复用其编号，否则返回 false。正常播放期间没有每帧扫描
3. 递增槽位版本，登记借出，构造本轮租约。在实例失活时同步调用 `configure(instance, current)`。仅需默认配置时可传 null
4. 回调返回后检查本轮租约。若已提前归还、池已禁用或本轮已被清场，返回 false，输出仍为默认值。回调可在归还 A 后再次租到同一实例 B，外层 A 的后续步骤只检查 A 的版本
5. 本轮仍有效时调用 `SetActive(true)`。实例的 `OnEnable` 可能同步归还，因此激活后再次核对本轮租约，仍有效时才设置输出并返回 true
6. 配置抛出异常时，用**本轮租约**尝试归还并向调用方重抛原异常。A 自行归还并借出 B 后再抛错，B 继续有效。回滚时的重置异常单独记录，原始配置异常仍传回调用方

### TryRelease 与 IPoolReset

`bool PoolLease.TryRelease()` 同步尝试结束这一轮租用。false 表示调用时凭据已失效，true 表示本轮已结束，实例能否继续复用由重置结果决定

1. 回到租约记录的池核对槽位和版本。通过后先清除 `Rented`，再将实例失活。此时重复归还返回 false，正在清理的编号尚未回到闲置栈
2. 逐个调用缓存的 `void IPoolReset.ResetForReuse()`。组件在此释放本轮的外部订阅、清除粒子或临时数据，各组件负责自己的状态。清理期间触发的新租用只能领取其他可用编号
3. 全部成功时恢复父级和根节点局部姿态，最后把编号压回闲置栈
4. 任一重置组件抛错时，记录池名、组件类型和原始异常，继续清理其余组件。结束后销毁本实例、移除缓存，将编号归还。下一次取到该编号时创建干净实例，批量清场也会继续处理其他槽位

### 组件生命周期与外部销毁

| 入口 | 行为与调用方可见结果 |
| --- | --- |
| `Awake` | 先检查配置，缺失 Prefab 或数值越界会报告错误，池保持关闭。合法配置创建失活的创建节点、分配槽位并预热指定数量 |
| `OnEnable` | 初始化成功后开放租用。再次启用沿用已有实例、版本和容量 |
| `void RecycleAll()` | 暂停接受租用，逐槽结束有效租约，释放已丢失实例的借出标记。闲置实例保留，重复调用不会再次重置它们。完成后，原本启用的池继续服务 |
| `OnDisable` | 先关闭入口，再同步执行 RecycleAll。组件禁用、池节点失活都结束本轮借用，恢复启用后可重新租用 |
| `OnDestroy` | 启用池先经过禁用清场。销毁组件时清理所有仍存在的池实例和创建节点，只移除池组件时也能释放它们 |
| 外部销毁实例 | 闲置对象丢失时在下次领取其编号时重建。借出对象丢失时旧租约立即随 Unity 对象实际销毁而失效，在池满又收到请求或清场时回收该编号。`Destroy` 的测试须等待实际销毁完成，新实例仍使用新的租用版本 · [Unity 对象销毁时点](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/Object.Destroy.html) |

## 4. 火花 Prefab 与场景调用

`CombatDemo/HitSparkPool` 位于场景根。初始预热 1 份，最多同时租用 2 份。M7 连招的[扣血与火花联合用例](./M2.4%20Damage%20详细技术设计.md#combatdemo-连招联合算例)使用容量 1 的独立配置。M2.1 可以直接在场景中租用火花，后续战斗表现订阅者收到扣血事实后再调用相同入口

`HitSpark.prefab` 根节点配置非循环 ParticleSystem，关闭 Play On Awake，Stop Action 选 None，时长 0.2 秒，粒子寿命 0.18 秒，在 0 秒发射一组 12 个粒子。Renderer 使用 PoolParticle。`PooledHitSpark` 在 `OnEnable` 播放，在协程中用 `IsAlive(true)` 等待包含子系统的本轮播放完成，再用捕获的租约归还。手动归还时对象失活会停止协程，`ResetForReuse` 随后清空残留粒子 · [Unity 粒子存活状态](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/ParticleSystem.IsAlive.html)

```csharp
bool played = hitSparkPool.TryRent((instance, current) =>
{
    instance.transform.SetPositionAndRotation(hitPoint, hitRotation);
    instance.GetComponent<PooledHitSpark>().Bind(current);
}, out var lease);
```

`played` 为 false 时表现方跳过本次火花。需要自动归还的火花在配置回调中调用 `Bind(current)`，自然播完时由该轮协程归还。需要提前结束也可以调用输出租约的 `TryRelease()`

## 5. 一次完整的复用走查

取容量与预热量均为 1 的池，Prefab 根的局部缩放为 (1, 1, 1)，A 配置位置 P 并把缩放改为 (3, 3, 3)，B 配置另一个位置 Q

| 步骤 | 文件与状态变化 | 可观察结果 |
| --- | --- | --- |
| Rent A | ScenePrefabPool 从 `available` 取槽 0，`Rented = true`、`Version = 1`，PoolLease 保存原池、0、1 | A 有效，实例仍失活 |
| Configure A | 调用方写入 P 与缩放，PooledHitSpark.Bind 接收 A | 配置期间尚未播放，可以提前归还 |
| Activate A | ScenePrefabPool 激活对象，PooledHitSpark 捕获 A 并播放 | TryRent 返回 true，可在 P 看到火花 |
| Release A | A 回原池核对槽 0 的版本 1，清 `Rented`，失活对象 | 所有 A 的副本失效，槽 0 在重置完成前仍不可借 |
| Reset | PooledHitSpark 清除粒子，池恢复 Prefab 局部姿态，槽 0 入栈 | 不必销毁健康实例，闲置时对象不可见 |
| Rent B | 同一槽、同一对象，`Version = 2`，在失活状态下设置 Q 后重新激活 | B 配置时看到单位缩放和空粒子，A 的迟到回调返回 false，Q 处的火花继续播放 |
